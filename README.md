# Bifurcation, Optimal Control, and Cost-Effectiveness Analysis of a Nonlinear Suicidal Behavior
Mathematical modeling and analysis of nonlinear suicidal behavior dynamics using bifurcation theory, optimal control, parameter estimation, sensitivity analysis, and cost-effectiveness analysis. The project investigates persistence mechanisms, intervention strategies, and policy-oriented decision support.

## Overview
This repository contains mathematical and computational models for studying nonlinear suicidal behavior dynamics through deterministic compartmental modeling, bifurcation analysis, parameter estimation, optimal control, and cost-effectiveness analysis.

The model incorporates social and behavioral influences, mental vulnerability, suicidal ideation, suicide attempts, treatment, recovery, and relapse dynamics to understand persistence mechanisms and evaluate intervention strategies.

## Features

- Deterministic compartmental suicide model
- Basic reproduction number analysis
- Local and global stability analysis
- Forward and backward bifurcation analysis
- Parameter estimation using U.S. suicide mortality data
- Global sensitivity analysis:
  - Latin Hypercube Sampling (LHS)
  - Partial Rank Correlation Coefficients (PRCC)
- Optimal control analysis
- Forward–Backward Sweep Method (FBSM)
- Cost-effectiveness analysis
- Numerical simulations of intervention strategies

## Model Compartments

- S: Susceptible individuals
- M: Mentally vulnerable individuals
- I: Ideators
- As: Non-fatal suicide attempters
- Af: Fatal suicide attempts (cumulative deaths)
- T: Treatment
- R: Recovery
